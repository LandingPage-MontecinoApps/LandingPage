1. Introducción

Esta Política de Privacidad aplica exclusivamente a la aplicación Manual de Procedimientos SAMUR‑PC, desarrollada por MontecinoApps.

La aplicación es una herramienta de consulta destinada a profesionales y estudiantes del ámbito sanitario.

No recopila datos personales, no realiza seguimiento del usuario y no transmite información a servidores externos.

Cumplimos con el Reglamento General de Protección de Datos (RGPD) y con las Políticas de Datos de Usuario de Google Play.

2. Datos que NO recopilamos

De acuerdo con las categorías definidas por Google Play, la aplicación NO recopila, procesa ni comparte ninguna de las siguientes categorías de datos:

  • Información personal: nombre, email, teléfono, dirección, identificadores.
  • Información financiera: datos bancarios, tarjetas, pagos.
  • Información de salud o bienestar: datos médicos, fisiológicos, biométricos o clínicos.
  • Información biométrica: huellas, rostro, voz.
  • Información de ubicación: GPS, ubicación aproximada o precisa.
  • Actividad del usuario: interacciones, clics, navegación, hábitos.
  • Fotos, vídeos o archivos del dispositivo.
  • Contactos o calendario.
  • Mensajes o comunicaciones.
  • Identificadores del dispositivo: de publicidad, IMEI, etc.
  • Datos de uso o analítica
  • Datos sensibles: religión, orientación sexual, raza, etc.
  • Datos de publicidad o seguimiento

La aplicación no solicita permisos del sistema relacionados con estas categorías.

3. Datos introducidos por el usuario

La aplicación permite introducir texto en un buscador interno.

Este texto:

  • Se procesa exclusivamente en el dispositivo.
  • No se almacena.
  • No se envía a servidores.
  • No se vincula a ninguna identidad.
  • Se elimina automáticamente al cerrar la aplicación.

Google Play considera el texto libre como “potencialmente sensible”, por lo que lo declaramos explícitamente aunque no se recoja ni procese.

4. Datos de salud (Health Data)

La aplicación NO recopila, procesa ni almacena datos de salud del usuario

En concreto:

  • No solicita datos médicos, fisiológicos o biométricos.
  • No registra historiales clínicos ni constantes vitales.
  • No accede a repositorios de salud del sistema (Google Health Connect, Apple HealthKit).
  • No realiza diagnósticos ni monitorización.
  • No permite introducir información clínica identificable.

El contenido de la app es informativo y educativo, no médico.

5. Ubicación

La aplicación:

  • No solicita permisos de ubicación.
  • No accede al GPS.
  • No rastrea la posición del usuario.
  • No utiliza APIs de geolocalización del sistema.

Aunque se muestra un mapa, este se utiliza únicamente para visualizar contenido estático.

La app no obtiene ni procesa la ubicación del usuario.

6. SDKs y capacidades técnicas

La aplicación utiliza SDKs de terceros (como Google Maps) que tienen capacidades técnicas para acceder a datos sensibles, incluida la ubicación.

Sin embargo:

  • La app no utiliza dichas capacidades.
  • No solicita permisos sensibles.
  • No accede a datos personales.
  • No transmite información a terceros.

Declaramos esta sección para cumplir con los requisitos de Google Play.

7. Finalidad del tratamiento

La aplicación no realiza tratamiento de datos personales.

El buscador interno procesa texto únicamente para mostrar resultados dentro de la app.

8. Conservación de datos

La aplicación no almacena datos personales. Por tanto:

No existe retención, registro ni historial de uso.

9. Compartición de datos

No compartimos datos con terceros porque no recopilamos ninguno.

La app no utiliza servicios de analítica, publicidad ni seguimiento.

10. Transferencias internacionales

No se realizan transferencias internacionales de datos.

11. Menores de edad

La app puede ser utilizada por cualquier persona.

No se recopilan datos, por lo que no existe riesgo de tratamiento indebido.

12. Derechos del usuario

Aunque no tratamos datos personales, puedes contactar con nosotros en: montecinoapps@gmail.com

13. Enlaces externos

La app puede incluir enlaces a páginas web externas

Al abrirlos, el usuario abandona la app y queda sujeto a las políticas de privacidad de dichos sitios.

La app no envía ningún dato al abrir estos enlaces.

14. Cambios en esta política

Podemos actualizar esta política ocasionalmente.

Publicaremos la versión actualizada en la ficha de Google Play.
